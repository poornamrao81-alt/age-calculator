Age Calculator

A beginner-friendly Python project that calculates a user's current age based on their date of birth and also calculates the number of days remaining until their next birthday.

📌 Project Purpose

This project was created to practice working with dates, user input, conditional statements, and basic calculations in Python.

✨ Features
Takes the user's name as input
Takes the date of birth in DD-MM-YYYY format
Automatically gets the current date
Calculates the user's current age
Checks whether the birthday has occurred this year
Calculates the number of days remaining until the next birthday
🛠️ Concepts Used
Python
datetime module
date.today()
User input with input()
split()
map()
if statements
Date subtraction
📚 Learning Outcome

Through this project, I practiced using Python's datetime module and learned how to work with dates, compare dates, calculate age, and find the number of days between two dates.
